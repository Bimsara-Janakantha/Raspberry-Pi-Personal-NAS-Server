# Phase 3 — Drive Preparation

All drives need to be wiped and initialized before being placed in the enclosure, as it is much easier to do this with drives connected directly to a Windows laptop.

**Tool:** Windows `diskpart` utility (built-in, no installation needed)

**Steps for each drive:**

1. Connect the drive to your Windows laptop via a USB-to-SATA adapter (or directly to a SATA port).

2. Open a Command Prompt **as Administrator** and launch diskpart:

   ```cmd
   diskpart
   ```

3. List all available disks:

   ```cmd
   list disk
   ```

4. Select the target disk (replace `X` with the correct disk number — **double-check this**):

   ```cmd
   select disk X
   ```

5. Wipe the disk completely (this is **destructive** and irreversible):

   ```cmd
   clean
   ```

6. Initialize the disk with a GPT partition table (required for drives > 2TB):

   ```cmd
   convert gpt
   ```

7. Exit diskpart and repeat for each drive.

> ⚠️ **Warning:** `clean` will erase all data on the selected disk. Confirm you have selected the correct disk number before proceeding. Triple-check using `list disk` and comparing sizes.
