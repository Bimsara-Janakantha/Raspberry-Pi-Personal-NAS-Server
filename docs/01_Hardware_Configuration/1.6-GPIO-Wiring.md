# Phase 6 — GPIO Wiring (LEDs & Buzzer)

The PC case's built-in LEDs and a buzzer are wired to the Raspberry Pi GPIO to provide visual and audio feedback without any additional software dependencies beyond GPIO control.

> ⚠️ **Important:** Raspberry Pi GPIO pins operate at **3.3V** and have a maximum current of ~16mA per pin. Always use a **current-limiting resistor** (330Ω–470Ω) in series with each LED to prevent damage to the GPIO pins.

## 6a — Power LED (Green) → GPIO 17

| Connection | Detail                                     |
| ---------- | ------------------------------------------ |
| GPIO Pin   | 17 (Physical Pin 11)                       |
| LED Color  | Green                                      |
| Purpose    | Indicates system is powered on and running |
| Resistor   | 330Ω in series                             |

**Wiring:**

1. Locate the green LED connector from the PC case front panel bundle.
2. Connect the **anode (+)** through a 330Ω resistor to **GPIO 17**.
3. Connect the **cathode (−)** to any **GND** pin on the Pi (e.g., Physical Pin 9).
4. Use shrink tubing on all exposed joints.

## 6b — Disk Activity LED (Red) → GPIO 27

| Connection | Detail                                           |
| ---------- | ------------------------------------------------ |

## 6c — Temperature Warning Buzzer → GPIO 16

| Connection | Detail                                                     |
| ---------- | ---------------------------------------------------------- |
| GPIO Pin   | 16 (Physical Pin 36)                                       |
| Component  | Active 5V Buzzer                                           |
| Purpose    | Audible alert when CPU/drive temperature exceeds threshold |

> ⚠️ **Active buzzer note:** An active buzzer has an internal oscillator and emits a tone when 5V is applied. Since GPIO pins output only 3.3V, you must drive the buzzer via a **transistor switch** (e.g., NPN 2N2222 or BC547). GPIO 16 drives the transistor base; the buzzer is connected between 5V and the collector; emitter goes to GND.

**Wiring (with NPN transistor):**

```shell
GPIO 16 ──[1kΩ]──► Base (NPN transistor)
5V       ─────────► Buzzer (+) ──► Collector
GND      ─────────► Emitter
                     Buzzer (−) ──► Collector
```
