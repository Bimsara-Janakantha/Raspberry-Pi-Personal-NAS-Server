# Web Browser Access

The simplest way to access the NAS — no software to install, works from any device with a browser.

---

## Steps

1. Open any web browser (Chrome, Firefox, Safari, Edge).
2. Navigate to your Nextcloud address:
   ```
   https://cloud.mynas.dev
   ```
3. Enter your Nextcloud username and password.
4. You will land directly in your personal vault.

---

## What You Can Do From the Browser

- Upload and download files
- Create folders and organise your storage
- Preview photos, PDFs, and documents
- Share files with others via public links
- View your storage quota usage
- Manage connected devices and app passwords

---

## Accessing the Server Address

If you are unsure of the server address, you can find it inside Nextcloud:

1. Click the **profile icon** in the top right corner.
2. Click **Settings**.
3. In the left panel, click **Mobile & Desktop**.
4. The server address is shown there — copy it for use in the mobile and desktop apps.
